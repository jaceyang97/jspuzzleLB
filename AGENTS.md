# Working with UI SDK

Before using UI SDK, follow the `ui-sdk` skill if it is installed and read `node_modules/@ui-sdk/react/docs/llms.txt` for the installed version.

When building a new component, also search `node_modules/@ui-sdk/react/docs/core.md` by heading for the behaviors you need and read `node_modules/@ui-sdk/react/docs/rendering.md`.
