# Handwriting fonts for header studies

These unmodified font files come from the official [Google Fonts repository](https://github.com/google/fonts), checked on 6 September 2026. They are included for the design comparison boards. Each family is licensed under the SIL Open Font License 1.1; its full copyright notice and license are included alongside the fonts.

| Local font | Official source | Included license |
| --- | --- | --- |
| `PatrickHand-Regular.ttf` | [Patrick Hand](https://github.com/google/fonts/blob/main/ofl/patrickhand/PatrickHand-Regular.ttf) | `PatrickHand-OFL.txt` |
| `Caveat.ttf` | [Caveat variable font](https://github.com/google/fonts/blob/main/ofl/caveat/Caveat%5Bwght%5D.ttf) | `Caveat-OFL.txt` |
| `Kalam-Regular.ttf` | [Kalam Regular](https://github.com/google/fonts/blob/main/ofl/kalam/Kalam-Regular.ttf) | `Kalam-OFL.txt` |
| `Kalam-Bold.ttf` | [Kalam Bold](https://github.com/google/fonts/blob/main/ofl/kalam/Kalam-Bold.ttf) | `Kalam-OFL.txt` |
| `Handlee-Regular.ttf` | [Handlee](https://github.com/google/fonts/blob/main/ofl/handlee/Handlee-Regular.ttf) | `Handlee-OFL.txt` |
| `IndieFlower-Regular.ttf` | [Indie Flower](https://github.com/google/fonts/blob/main/ofl/indieflower/IndieFlower-Regular.ttf) | `IndieFlower-OFL.txt` |
| `ShadowsIntoLight-Regular.ttf` | [Shadows Into Light](https://github.com/google/fonts/blob/main/ofl/shadowsintolight/ShadowsIntoLight.ttf) | `ShadowsIntoLight-OFL.txt` |

`Caveat.ttf` is the original `Caveat[wght].ttf` file with a simpler local filename. `ShadowsIntoLight-Regular.ttf` is the original `ShadowsIntoLight.ttf` file renamed to match the comparison board. Their internal font data is unchanged.

The additional fonts and their license files were downloaded through the GitHub contents API. Local bytes were checked against the API's Git blob SHA-1 identifiers; every font also passed its TrueType signature check.
