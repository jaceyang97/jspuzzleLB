## Data updates

[GitHub Actions](https://github.com/jaceyang97/jspuzzleLB/actions/workflows/update-puzzles.yml) checks the public puzzle pages daily at **12:00 UTC / 20:00 Shanghai time**. When the lists change, it updates the data and rankings, then redeploys the site. It also rechecks recently archived puzzles for late additions.
