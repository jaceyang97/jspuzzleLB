# Header handwriting

`Caveat.ttf` is the unmodified Caveat variable font from the existing local
`prototypes/legacy-public-designs/fonts/Caveat.ttf` comparison asset. Its original source is the
[Google Fonts Caveat family](https://github.com/google/fonts/tree/main/ofl/caveat).
The included `Caveat-OFL.txt` contains the copyright notice and SIL Open Font
License 1.1.

The header uses weight 600 for the word `unofficial`. The build bundles and fingerprints this file independently of the archived
design pages. The selected leaderboard uses the subset in `public/fonts/`.
