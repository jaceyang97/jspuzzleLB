# Header handwriting

`Caveat.ttf` is the unmodified Caveat variable font from the existing local
`public/designs/fonts/Caveat.ttf` comparison asset. Its original source is the
[Google Fonts Caveat family](https://github.com/google/fonts/tree/main/ofl/caveat).
The included `Caveat-OFL.txt` contains the copyright notice and SIL Open Font
License 1.1.

The header uses weight 600 for the word `unofficial`. Keeping the font beside
the production CSS lets the app bundle and fingerprint it independently of
the design comparison pages.
